# MIA Campus

Portfolio demo of a student information system by **MIA Solutions Pvt. Ltd.**

Static Next.js front-end with sample data only — no API or database.

## Run locally

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:3000
